# Proyectonoties 🚀

Sistema integral desarrollado con una Arquitectura Desacoplada utilizando .NET Core, separando la lógica de negocio (Backend) de la interfaz de usuario (Frontend).

## 🛠️ Stack Tecnológico
- **Backend:** ASP.NET Core Web API (C#)
- **Frontend:** ASP.NET Core MVC (C#)
- **UI/UX:** CSS Personalizado, Tipografía Poppins
- **Gestión de Versiones:** Git & GitHub

## 📂 Estructura del Proyecto
El proyecto está organizado en una solución de Visual Studio con dos bloques principales:
- **/Backend.API**: Servidor encargado de la lógica, modelos de datos y servicios REST.
- **/Frontend.Web**: Aplicación cliente que maneja las vistas (Razor), controladores de navegación y estilos.
